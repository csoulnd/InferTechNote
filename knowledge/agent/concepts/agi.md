# AGI（通用人工智能）

## 核心问题

AGI 是什么，它与擅长特定任务的 AI 系统有什么区别？

## 一句话解释

AGI（Artificial General Intelligence，通用人工智能）是指能够跨广泛任务和领域学习、推理、迁移知识并处理新情境，整体能力达到或超过人类水平的人工智能系统。

## 详细解释

当前多数 AI 系统即使在某些任务上超过人类，也可能依赖特定训练分布、工具链或人工编排。AGI 强调的不是单项峰值，而是能力的**广度**、**水平**与**适应性**：系统能否在许多不同任务上达到足够高的表现，并把已有知识迁移到未专门训练的新问题。

AGI 尚无统一定义。常见定义关注点包括：

| 关注点 | 要回答的问题 |
| --- | --- |
| 广度 | 能否覆盖广泛任务和领域，而非只解决一种问题？ |
| 水平 | 与普通人、熟练成人、专家或所有人相比，能力达到什么程度？ |
| 学习与迁移 | 能否高效学习新技能，并将知识用于陌生情境？ |
| 自主性 | 能否在较少人工干预下完成长期、复杂目标？ |
| 现实影响 | 能否完成大多数具有经济价值的工作？ |

这些维度不应混为一个指标。例如，系统可以知识面很广但表现不稳定，也可以在围棋等狭窄领域远超人类而不具备通用性。

## 如何判断

一种可操作化思路是把 AGI 看成二维能力谱系：

```text
                 通用性（任务和领域的广度）
                              ↑
       专用超人系统           │          高水平 AGI
       单项很强、范围较窄      │          广泛且高水平
                              │
       狭窄辅助工具           │          广泛但能力有限
                              └────────────────────→
                                      表现水平
```

评估时应同时说明任务集合、对照人群、成功阈值、学习条件、工具与资源限制，以及系统需要多少人工协助。单一基准、演示或某项超人表现不足以独立证明 AGI。

## 与相邻概念的区别

| 概念 | 与 AGI 的区别 |
| --- | --- |
| AI | 总称，包含规则系统、专用模型和通用系统；AGI 是其中尚有争议的目标类别。 |
| Narrow AI | 针对有限任务或领域优化，即使单项超过人类也不等于 AGI。 |
| LLM | 一类通过语言建模训练的模型；它可能成为 AGI 系统的组件，但两者不是同义词。 |
| Agent | 围绕目标调用模型、工具和环境的运行系统；自主执行能力不自动意味着通用智能。 |
| ASI | Artificial Superintelligence，通常指在几乎所有相关认知领域显著超过人类的系统。 |

## 适用边界

- 目前不存在被学术界和产业界共同接受的 AGI 定义或单一判定测试。
- “达到人类水平”必须说明对照人群、任务范围和测量方法，否则无法验证。
- 自主性、具身能力、意识和主观体验是否属于 AGI 的必要条件，仍存在定义分歧。
- 本文解释能力概念，不预测 AGI 的实现时间、技术路线或社会影响。
- 对某个现有系统是否属于 AGI，应依据明确评测框架和可复现实证，而不是厂商命名或个别演示。

## 实践意义

- 讨论 AGI 时先声明采用的定义、任务范围和能力阈值，避免不同标准下的结论被直接比较。
- 评估系统应同时覆盖广度、表现、迁移和自主性，并记录工具、算力与人工协助条件。
- 产品设计不应以“是否 AGI”代替具体需求，应分别验证可靠性、安全性、成本和目标任务能力。

# DSH 企业级接入与能力集成需求

## 需求目标

基于[第三方智能体上架管理服务平台侧迁移](third-party-agent-listing-platform-migration.md)成果，分阶段完成 DSH 企业级部署、Hint 加速插件接入、使用体验优化，以及一体机平台记忆库和知识库能力对接。

## 分阶段需求与验收标准

| 阶段 | 需求描述 | 验收标准 |
|---|---|---|
| 1. 企业级部署接入 | 在平台迁移基础上增量开发，完成 DSH 适配及企业级部署接入。 | DSH 在目标环境部署成功，可通过平台完成上架、启动及基本任务执行。 |
| 2. 加速库接入 | 接入 Hint 加速插件，完成收益验证及插件企业级部署。 | 插件可部署、启用和停用；在相同环境及任务集下完成开启前后的对比测试，提供性能收益与任务质量验证报告。收益指标及达标阈值待确定。 |
| 3. 体验优化 | 优化企业级部署场景下的启动时长，开发远程文件下载插件，并按确认清单完成其他体验优化。 | 启动时长达到约定目标；远程文件下载插件通过功能、权限及异常场景验证；优化清单逐项验收。启动计时口径及目标值待确定。 |
| 4. 记忆库与知识库对接 | 对接一体机平台的记忆库和知识库能力，供 DSH 在任务执行中使用。 | DSH 可按用户权限读写记忆、检索知识，并将结果用于任务执行；权限隔离及接口异常场景验证通过。 |

## 涉及组件

Manager-Platform（名称待确认）、DSH、Hint 加速插件、远程文件下载插件、一体机平台记忆库及知识库服务。
